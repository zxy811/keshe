| 用户/课设要求 | 本包实现 | 当前验证情况 |
|---|---|---|
| 在提供的代码上修改 | 保留 PLL/SDRAM/CTR 板级路径、符号和原包 | 原包 SHA256 可核对，改动见修改说明 |
| LPF/BPF/BRF，1—10 kHz | 32 kHz、257 抽头、28 组 Q15 系数 | 全部频响已由 SciPy 分析 |
| 给出滤波系数 | tables.c、filter_coefficients.csv 全量 7196 抽头 | 已生成并与 C 内表对应 |
| Matlab 波特图 | matlab/run_all.m，全部幅相图 | MATLAB 本体待本地运行；GNU Octave 9.4.0 已完整执行，输出 30 张图 |
| FFT C 实现 | 独立 DIT、256 点、逐级缩放 | GCC 实际执行并与 NumPy FFT 比较 |
| FFT 汇编实现 | 独立 DIF 描述经 cl55 生成 .asm 后再汇编 | 尚未目标编译；不是手写汇编，如教师要求手写则未满足 |
| 专业部分任选其一 | 选择 AM/DSB，一维消息 + 图像行样本演示 | 载波及双边带数值已验证 |
| 数字按键对应功能 | 1—7 功能、8 频率、9 图源 | 主机状态机已验证，实物按键待验证 |
| 电脑刷新图片结果 | CCS 图像窗口，或导出 .dat 后主机查看器刷新 | 文件协议与主机处理已验证，JTAG 导出待板卡验证 |
| 图片来源及存放位置 | 主机加载→6400字 .dat→dbUserImage；原生内置图源 | 转换及边界卷积已验证 |
| 虚拟机设置与下载过程 | 操作手册区分 Windows 主机、XP/Ubuntu 客体 | 依据原工程，具体实物环境未确认 |
| 实践下载/固化 | C5509 构建、RAM 下载、板卡验收流程 | 云端没有硬件；FLASH 工具和参数待板型确认 |
| 论文 5000—10000 字，中英文摘要 | 课程报告 Word/Markdown，数值与来源标注 | 实践章节为待实测，不能冒充已完成 |
| 学校官方模板 | 当前通用课程设计格式 | 上传文件为评分标准，没有提供教务处专用模板 |

原始实习表列出多个选题与实践方向；本包按用户明确选择的滤波器、FFT 和 AM/DSB 展开，不虚构其他选题功能。FLASH 是否为本组必做项以教师最终选题要求为准。

大型 PDF 因超过单文件 32 MiB 的传输限制未读取。板型冲突是实际下载前的必要确认项，不能凭文件名做电气连接或烧写决定。
